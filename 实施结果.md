## T14 交付摘要

- 新增只读 PM tools：`repo_map`、`impact_analysis`、`event_query`、`session_summary`、`artifact_read`。
- `repo_map` 有 `max_files`、`max_depth`、扫描预算和截断标记，只返回路径/目录/入口/测试目录等结构化事实，不读取文件正文。
- `impact_analysis` 明确输出 `deterministic=false`、`confidence=heuristic`，只给候选文件、测试建议和风险，不声称确定性结论。
- `event_query` / `session_summary` 只使用当前 runtime session 的 timeline；PM 传入 `session_id` / `task_id` 会返回 `invalid_args`。
- `artifact_read` 只允许读取当前 workspace/main workspace 的 `.foreman/tool-logs` artifact，普通 workspace 文件和 path traversal 会被拒绝。
- Context v2 会把 `test_run` tool result 作为 key test result 保留到 runtime state / compact restore。
- Briefing prompt 会先带结构化 runtime facts，再带压缩后的事件尾部，避免只重复长事件文本。
